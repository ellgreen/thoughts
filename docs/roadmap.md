# Roadmap

Each milestone is usable on its own. A milestone is done when `task check` is
green and it has been looked at on a phone and a desktop.

## M0: Direction

- [x] Three directions prototyped; the two-ink zine chosen (`design.md`)
- [x] Logo: mark, wordmark and lockup as SVG (`docs/brand/`)

## M1: Foundation

- [x] `v2` branch, `1.x` for v1 fixes
- [x] Config, SQLite with WAL and foreign keys, migration runner
- [x] Refuse to open a v1 database until the importer exists
- [x] Auth drivers behind one interface; name sign-in
- [x] Sessions, sign-in screen and `/login?redirect=` in the new design
- [x] Multi-arch Dockerfile (distroless), CI, release workflow
- [x] Playwright against the real binary on desktop and phone

## M2: The retro

- [x] Create a retro: templates, columns, tags, unlisted
- [x] Reflect with hidden notes (author and image hidden too), Group, Vote,
      Discuss, reactions, actions, GIFs, Markdown export, presence
- [x] Realtime: a projected board per person after every change, a fresh
      board on reconnect (see decisions)
- [x] Vote limits (stackable, like dot stickers) and stage rules enforced on
      the server
- [x] Keyboard: one shortcut registry, `?` sheet, ⌘K palette
- [x] v1's obfuscation e2e, now a two-person run of a whole retro
- [x] Home and `/tags/{tag}` with open actions

## M3: Upgrade from v1

- [x] Detect, back up and import a v1 database in one transaction
- [x] Real v1 fixtures from 1.2.1 and 0.3.0, made by driving those releases
      through their own API
- [x] Keep v1 sessions signed in as the same person
- [x] `docs/upgrading.md`
- [x] Rehearsed on a real dev database and in Docker with a v1 volume

## M4: Sign-in drivers

- [x] LDAP without a service account, with an optional required group
- [x] OIDC with PKCE, lazy discovery and an optional required group
- [x] Sign-in page for several drivers at once
- [x] Live tests against OpenLDAP and Dex (`task test:auth-live`, and CI)

## M5: AI

- [x] Drivers: OpenAI, Anthropic, OpenAI-compatible, GitHub Copilot SDK
- [x] Templates from a theme, suggested groups, group names, draft actions,
      recap; suggestions the room applies or dismisses
- [x] Copilot checked live, both with the CLI on PATH and as a headless
      sidecar; Anthropic, OpenAI and OpenAI-compatible are only checked
      against a fake model (no keys here yet)

## M6: Facilitation and teams

- [x] Timer that keeps to the server's clock, with an optional chime
- [x] Ready check: "I'm done", counted against who's in the room
- [x] Spotlight ("bring everyone here") with follow, and one-at-a-time focus
- [x] Teams at `/t/{slug}`; a tag can become a team
- [x] Last time first: a team's open actions from earlier retros, each
      done, carried over (copied, linked back) or dropped

## M7: Release

- [x] README and screenshots (regenerated by `ui/e2e/screenshots.spec.ts`)
- [x] Upgrade notes (`docs/upgrading.md`) and release notes (`docs/releases/2.0.0.md`)
- [x] axe accessibility check on every screen in light and dark
- [ ] Merge `v2` into `main`, tag 2.0.0 and publish the release (needs Ellis)
