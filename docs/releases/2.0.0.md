# thoughts 2.0.0

thoughts 2 is a rebuild from the ground up: a new design, keys for the
common things, a way to run the room together, actions that carry from one retro to the
next, more ways to sign in, and AI from the provider you choose. It's still
one small image on SQLite, and upgrading is a tag bump.

## Upgrading

```bash
docker pull ghcr.io/ellgreen/thoughts:2
```

On first start v2 copies your v1 database to
`thoughts.v1-backup-<date>-<time>.sqlite`, then converts it in one
transaction. If anything fails, nothing changes. Links to retros and tags
keep working, and people signed in to v1 stay signed in as themselves.
Every v1 setting keeps its meaning. Read [upgrading.md](../upgrading.md)
first, especially if your volume came from an image older than 1.0.0.

## What's new

- **A new look.** A two-ink print: notes in fluoro pink and riso blue, and
  where notes overlap in a group, the inks overprint. Light and dark.
- **Keyboard.** Keys for what you do most: `[` `]` between stages, `a` for
  an action, `t` for the timer. `?` lists them and `⌘K` finds any action or
  retro.
- **Hidden means hidden.** While reflecting, other people's notes carry no
  text, no author and no image, on the server and over the wire.
- **Votes stack**, like dot stickers, and the server holds everyone to their
  limit.
- **Run the room.** A shared timer, an "I'm done" count, a spotlight that
  brings everyone to one group, and one-group-at-a-time focus.
- **Teams and "last time first".** Retros can belong to a team, at
  `/t/<team>`, and a tag can become a team. A team's next retro opens with
  the actions its last one left open: done, carried over or dropped.
- **Sign in with LDAP or OIDC**, alongside or instead of a name. LDAP binds
  as the person signing in, so there's no service account to manage.
- **AI drivers.** Anthropic, OpenAI, any OpenAI-compatible server (Ollama,
  vLLM, LiteLLM) or GitHub Copilot. Beyond v1's themed columns, it can
  suggest groups and names, draft actions and write a recap. Suggestions are
  shown to the room and applied only when someone chooses to.
- **Multi-arch image**, about 35 MB, for amd64 and arm64.

## Changed or removed

- The board's API is new, and v1's JSON endpoints are gone. Only the browser
  URLs are kept.
- `THOUGHTS_UI_ADDRESS` and `THOUGHTS_TENOR_API_KEY` are ignored.
- v1's "brainstorm" stage is called Reflect.
- Tasks are called actions.
